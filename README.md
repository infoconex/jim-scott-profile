# Jim Scott — Professional Profile & Resume

A fast, accessible, dependency-free profile site for engineering leader Jim Scott.

## Pages

- `dist/index.html` — executive profile, experience, leadership philosophy, open-source work, and writing.
- `dist/resume.html` — resume view with dedicated print styling, usable with the browser’s **Save as PDF** feature.

## Run locally

Open `dist/index.html` directly in a browser or serve `dist/` using any static HTTP server. The site has no build step and no runtime dependencies.

## Hosting

`.openai/hosting.json` declares the static output directory for ChatGPT Sites. The same `dist/` files can also be hosted by any static web host.

## Update content

The profile and resume are plain HTML with shared CSS in `dist/assets/styles.css`. Content is intentionally authored and reviewed rather than synthesized at runtime. Keep the two pages in sync when changing experience or skills.

## Content-review checklist before public launch

- Confirm exact dates and titles for each Concord Technologies role and add measurable outcomes where publishable.
- Decide whether to publish a professional contact email or keep LinkedIn as the contact channel.
- Review the education and Scrum Alliance credential details against the original records.
- Review open-source project descriptions and update them as projects evolve.
- Confirm portrait usage and desired imagery; the portrait was copied from Jim’s publicly available coding blog.

There is intentionally no personal phone number, home address, family information, compensation information, or contact form collecting visitor data.
